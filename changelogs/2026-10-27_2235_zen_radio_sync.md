# Changelog: 2026-10-27 22:35 - Zen Radio Sync Support

## Part 1: Importer Core (`sync_difm.py`)

- **Issue**: Zen Radio (`zenradio.com`) stations were missing from Navidrome sync.
- **Previous State**: `NETWORK_CONFIG` only contained 5 networks (`di`, `radiotunes`, `jazzradio`, `rockradio`, `classicalradio`). Stream URLs assumed direct mount syntax `/{chan_key}{stream_suffix}`.
- **Fix Applied**:
  - Added optional `stream_prefix` to `NETWORK_CONFIG`.
  - Added `zenradio` network definition with `stream_prefix: "zr"`, `domain: "zenradio.com"`, and `stream_host: "prem2.zenradio.com"`.
  - Updated `stream_url` construction to include `stream_prefix`.
  - Added `zenradio` to the default network list in CLI arguments.
- **Rationale**: AudioAddict serves 39 Zen Radio stations at native 320 kbps MP3 on `prem2.zenradio.com:80`, but mounts every stream under the `zr` prefix (e.g. `zrambient`).
